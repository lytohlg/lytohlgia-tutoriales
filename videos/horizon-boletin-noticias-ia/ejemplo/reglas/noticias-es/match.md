# Perfil de noticias de tecnología (en español)

Usa este perfil para novedades relevantes de ingeniería de software, inteligencia artificial, aprendizaje automático, sistemas, hardware, código abierto y la industria tecnológica.

Son típicos de este perfil: lanzamientos sustanciales, resultados de investigación, incidentes de seguridad, anuncios de la industria, análisis técnicos ligados a un evento reciente y debates de comunidad que aportan información práctica.

No uses este perfil para contenido cuya utilidad principal sea un ensayo largo, un tutorial paso a paso, un artículo académico completo, cobertura financiera, actualizaciones rutinarias o material promocional sin información sustantiva.

Escribe siempre en español neutro.
